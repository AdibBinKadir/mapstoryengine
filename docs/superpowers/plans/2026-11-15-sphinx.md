# The Sphinx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A talking AR Sphinx: hold Speak, argue by voice, two correct riddle answers → the scripted "Not here." reveal.

**Architecture:** The laptop server (`server/`) hears (ElevenLabs Scribe), thinks (Gemini, persona + riddle judging) and speaks (ElevenLabs TTS → base64 WAV in the JSON reply). Unity records the mic, posts it, shows subtitles, plays the WAV, and counts correct answers in a pure `SphinxProgress`.

**Tech Stack:** Python 3.12 FastAPI + httpx + pytest; Unity 2019.4 C# 7.3, UnityWebRequest, JsonUtility, Microphone, AR Foundation 3.1.3, NUnit EditMode.

**Spec:** `docs/superpowers/specs/2026-11-15-sphinx-design.md`

## Global Constraints
- Unity 2019.4.41f2, C# 7.3 only; `UnityWebRequest`, not `HttpClient`; `ARSessionOrigin`, no AR Foundation 4+ APIs.
- Edit only `server/`, `Assets/Game/Net/`, `Assets/Game/Encounters/Sphinx/`, `Assets/Game/Sandbox/P2_Sphinx.unity` (+ docs under `docs/superpowers/`).
- Keys only in `server/.env`; tests must never call real APIs (conftest blanks keys, including `ELEVENLABS_API_KEY`).
- Every Unity asset committed with its Unity-generated `.meta`; `git add` explicit paths only.
- `python -m pytest server` passes before the PR.
- Server answers within `REQUEST_BUDGET_S` = 7.5 s; `TTS_TIMEOUT_S` = 3; ElevenLabs model default `eleven_flash_v2_5`, TTS `output_format=pcm_16000`, STT model `scribe_v1`.
- Reveal line (exact): `Fine. A deal is a deal. Lean closer, sailor... Ithaca is... Not here.` followed by laughter text `Ha! Ha ha ha!`. Clue text (exact): `Not here.`

## Wire format (both sides rely on it)
- Request state (JSON; `state` form field on `/sphinx/talk`): `{event, hp, max_hp, deaths, last_event, riddle_index, correct_count}`; `riddle_index = -1` before the intro.
- `/sphinx` reply: `{line, riddle, riddle_index, audio}`.
- `/sphinx/talk` reply: `{heard, line, riddle, riddle_index, answer_correct, verdict, reveal, audio}`; `verdict` ∈ `"correct" | "wrong" | "none"` (JsonUtility can't read a null bool); `riddle_index` = the current riddle after this turn; `audio` = base64 WAV or `null`.

## Review Focus
- Server reachable but TTS fails or is slow → reply still arrives in time with `audio: null`; Unity shows subtitles only.
- A reveal can't happen on the first correct answer, nor from a forged/LLM-only verdict without similarity.
- Abort while recording, while a request is in flight, or while her voice plays → mic off, no late callback touches destroyed objects, no sound after.
- Empty or silent recording → "deaf" line, no crash; recording > 8 s is cut at 8 s.
- Mic permission denied on iOS → a visible message, typed fallback still works.
